📖 คู่มือการใช้งานระบบติดตามโครงงาน

อย่าลืมอ่านคู่มืออย่างละเอียดเพื่อใช้ระบบติดตามโครงงานของคุณได้อย่างถูกต้อง

คู่มือการใช้งานระบบโครงงานนักศึกษา

1. รายกาารโครงงานที่ดูแล

• แสดงภาพรวมโครงงานทั้งหมดที่คุณดูแล

• สถานะปัจจุบันของแต่ละโครงงาน (เสนอหัวข้อ, ผ่านหัวข้อ, กำลังทำ, ยื่นสอบจบ, สอบผ่าน)

• คลิกปุ่ม "ดูรายละเอียด" เพื่อไปยังหน้าต่างๆ เช่น อนุมัติหัวข้อโครงงาน หรือ ติดตามความก้าวหน้า


2. อนุมัติหัวข้อโครงงาน

• แสดงรายการหัวข้อที่นักศึกษาส่งมา

• ตรวจสอบข้อมูล :

- ชื่อโครงงาน (ไทย/อังกฤษ)

- รายละเอียดโครงงาน

- นักศึกษา + สาขา

- รายละเอียดโครงงาน

- ไฟล์เสนอหัวข้อ

- อาจารย์ที่ปรึกษา + อาจารย์ที่ปรึกษาโครงงาน

- รายละเอียดโครงงาน

• Action :

• อนุมัติ

• ไม่อนุมัติ → ใส่เหตุผล/ความเห็นได้ในช่องว่าง

• กดปุ่มเพื่อบันทึกผล


3. จัดการสอบหัวข้อ

• เลือกวันสอบหัวข้อและกรรมการสอบ (3 คน)

• หลังสอบบันทึกผลสอบ :

• ผ่าน/ผ่านโดยมีการแก้ไข/ไม่ผ่าน

• ความคิดเห็นอาจารย์ช่วยให้นักศึกษาปรับปรุง


4. ติดตามความก้าวหน้าโครงงาน

• แสดงรายงานความก้าวหน้าของนักศึกษาตามสัปดาห์

• ดู งานที่ทำแล้ว, ปัญหา, แผนงานถัดไป, % ความก้าวหน้า, ไฟล์หลักฐาน

• อาจารย์สามารถ :

• ใส่ ความติดเห็น/ข้อเสนอแนะ

• ปรับ % ความก้าวหน้า ตามที่ประเมินจริง

• กด เซ็นรับทราบ


ข้อควรระวัง

• ตรวจสอบชื่อโครงงาน, นักศึกษา, ไฟล์ก่อนอนุมัติ

• ระบุวันสอบหัวข้อ/สอบจบอย่างรอบคอบ

• ปรับ % ความก้าวหน้าโดยอาจารย์เท่านั้น

• ตรวจไฟล์เล่มสมบูรณ์ก่อนกดลงนาม

• ใส่ความคิดเห็น/ข้อเสนอแนะชัดเจน

• ไม่แก้ไขไฟล์นักศึกษาโดยตรง

• รักษารหัสและข้อมูลนักศึกษาให้ปลอดภัย
